# The Slave and the Master

Landing page for the book *The Slave and the Master: How Nicotine Enslaves You… and How to Break Free for Good*.

Static site, no build step: open `index.html` in a browser, or host the folder on GitHub Pages / Netlify / any static host.

- `index.html` — page content
- `styles.css` — green & red theme, responsive layout
- `script.js` — slow-motion smoke animation, scroll reveals, notify form (front-end only for now)
- `assets/cover.jpg` — book cover (replace when the final cover is ready)
